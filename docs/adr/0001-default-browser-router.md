# 默认浏览器是链接选择器，不是网页浏览器

为了在其他软件将网页链接交给系统时弹出浏览器选择浮窗，DFBrowser 注册为 HTTP/HTTPS 的默认处理应用，再通过指定应用打开链接，而不调用默认打开方式，避免递归回到自身。用户已确认接受这一中转方案；不使用全局点击监听、辅助功能拦截或浏览器扩展，也不承诺拦截应用内置浏览器及浏览器内部导航。

第一版供当前 Mac 本地使用，只选择浏览器、不区分用户配置；每个请求必须由用户明确选择或取消，不设置超时自动打开，不存储浏览历史、不访问链接内容。开发和测试不会自动修改系统默认浏览器，用户在完成验收后自行设置，随时可改回。

网址规则（0.1.4 起）：用户可显式配置“域名模式 → 浏览器”的规则，匹配的请求直接用指定浏览器打开，不再弹出选择浮窗。规则本身就是用户的明确选择，因此不违背“由用户决定”的原则；仍不做基于历史的自动学习，只在用户勾选“以后都…”时保存精确域名规则。规则只保存模式和目标浏览器，不保存链接。目标浏览器缺失或打开失败时退回选择浮窗；按住 Option 可临时跳过规则。

0.1.1 把“注册为系统候选”和“设为默认”分离：前者只登记当前应用包，后者由用户在系统设置选择。旧版逐个设置 HTTP/HTTPS 的方式报错且状态可能不一致，因此不再沿用；状态必须同时核验两种协议的偏好和实际解析，失败或不完整不能显示已完成。
